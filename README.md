## 🚀 핵심 가치, 딱 세 가지!
* ### 🔥 만들고 공유하는 게 정말 쉬워요.
    * **뚝딱 만드는 포트폴리오**: 복잡한 거 다 빼고, 직관적인 화면에서 전문가처럼 포트폴리오를 금방 완성할 수 있어요.
    * **링크 하나로 끝**: 완성된 포트폴리오는 딱 링크 하나로 어디든 바로 공유할 수 있고, 수정도 바로바로 반영돼요.

* ### 📈 내 성장 이야기를 그대로 담아요.
    * **성장 기록 보관소**: 결과물만 보여주지 않아요. 개발하며 고민했던 과정, 기술적인 도전, 성장 스토리를 블로그처럼 기록하고 포트폴리오에 자연스럽게 연결해 드려요.

* ### 🌐 찾기 쉽고, 로딩도 빨라요.
    * **검색 엔진이 좋아해요**: 개인 페이지는 Nuxt.js의 서버 사이드 렌더링(SSR) 기술을 써서 만들었어요. 덕분에 검색 엔진이 내 포트폴리오를 더 잘 찾고, 남들보다 빠르게 보여줄 수 있어요.

## 🛠️ 기술 스택

### 💰 최고의 성능과 최소한의 비용
**Supabase**와 **Cloudflare Pages**의 강력한 무료 플랜을 활용해서 개발 초기 단계 및 일정 규모 이하의 서비스 운영에 추가 비용이 거의 발생하지 않도록 설계했어요.

### ⚙️ 완벽한 배포 자동화 (CI/CD)
**GitHub Actions**을 이용해서 배포 자동화를 완벽하게 구현했어요. 코드를 Push 하기만 하면, 빌드부터 배포까지 시스템이 알아서 척척 진행해 줘요!
